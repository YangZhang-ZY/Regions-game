# 篮球经理人 Demo 开发日志

这是一份给新手照着做的文档。目标是用 **10 个工作日** 做出一个能给别人试玩的小游戏：像《Reigns / 王权》那样左右滑卡牌，扮演篮球俱乐部经理做决定。

建议从 **2026 年 9 月 25 日** 开始，周末休息。第 10 个工作日是 **2026 年 10 月 8 日**。

做的时候只看当天那一节。不要提前把后面几天的功能一起写进去。

## 每天开工前看这三句

1. 打开的是 `Regions Project` 这个 Unity 工程，版本是 **Unity 6000.3.8f1**。

## 这个游戏最后长什么样

玩家是篮球俱乐部经理。每回合出现一张事件卡。

- 往右拖过一条线，再松手：选右边的方案，卡牌飞出。
- 往左拖过一条线，再松手：选左边的方案，卡牌飞出。
- 没拖够就松手：卡牌弹回中间。
- 选择之后，四项数值变化，然后出现下一张卡。

四项数值：

| 名字 | 英文（代码里用这个） | 画面上怎么显示 | 含义 |
|---|---|---|---|
| 球队实力 | Performance | 0 到 100 的数字 | 球队打得怎么样 |
| 球员士气 | Morale | 0 到 100 的数字 | 球员开不开心 |
| 粉丝影响力 | Fans | 0 到 100 的数字 | 有多少人关注球队 |
| 俱乐部财富 | Wealth | `$2.4M` 这种样子 | 俱乐部还有多少钱 |

一局一共 **10 张卡**，按固定顺序出现。打完第 10 张，出现赛季结算。财富变成 0 或以下，或者实力、士气、粉丝任意一项变成 0 或以下，立刻失败，可以重新开始。

十个商业概念（机会成本、定价、复利这些）写在卡牌的文字里。程序不给每个概念单独做一套系统。

这一阶段先不做：球员交易、比赛模拟、工资帽、存档、音效、随机抽卡。

## 开始之前：Unity 里这几个词

你现在还没有游戏脚本。下面这些词后面每天都会用到。

**Hierarchy（层级）**  
左边那一列，场景里实际存在的物体。比如一张卡、一块画布。

**Inspector（检视）**  
点中一个物体后，右边显示它的组件。脚本也是拖到这里才生效。

**Project（项目）**  
下面那一栏，硬盘上的文件。脚本、图片、卡牌数据都在这里。

**Canvas（画布）**  
所有界面文字和图片的父亲。卡牌要放在 Canvas 下面，不然拖不动。

**RectTransform**  
界面物体的位置和大小。普通 3D 物体用的是 Transform，界面用的是 RectTransform。

**Play（播放）**  
上面中间的三角按钮。点下去是在试玩。试玩时改的数字，停止之后会消失。脚本文件的修改会留下来。

**脚本名和类名必须一样**  
文件叫 `CardSwipe.cs`，里面第一行类就必须写 `public class CardSwipe`。不一样的话，Unity 会报错，脚本也拖不上去。

**这个工程只用新的 Input System**  
所以拖动靠的是场景里的 **EventSystem**，并且它上面要有 **Input System UI Input Module**。如果拖不动，先检查这个，不要先怀疑自己的代码。

### 5. 写拖动脚本

在 `Assets/Scripts` 里右键 → Create → MonoBehaviour Script，名字填 `CardSwipe`。等底部转圈结束。

双击打开，把里面全部换成下面这段。保存。

```csharp
using UnityEngine;
using UnityEngine.EventSystems;

public class CardSwipe : MonoBehaviour, IBeginDragHandler, IDragHandler, IEndDragHandler
{
    public float maxRotation = 12f;

    RectTransform rect;
    Canvas canvas;
    bool dragging;

    void Awake()
    {
        rect = GetComponent<RectTransform>();
        canvas = GetComponentInParent<Canvas>();
    }

    public void OnBeginDrag(PointerEventData eventData)
    {
        dragging = true;
    }

    public void OnDrag(PointerEventData eventData)
    {
        if (!dragging)
        {
            return;
        }

        float scale = canvas != null ? canvas.scaleFactor : 1f;
        rect.anchoredPosition += eventData.delta / scale;

        float tilt = Mathf.Clamp(rect.anchoredPosition.x / 300f, -1f, 1f);
        rect.localRotation = Quaternion.Euler(0f, 0f, -tilt * maxRotation);
    }

    public void OnEndDrag(PointerEventData eventData)
    {
        dragging = false;
    }
}
```

这段代码在做什么：

- `IBeginDragHandler`、`IDragHandler`、`IEndDragHandler` 是 Unity 界面的三个拖动接口。手指按下、移动、松开时，Unity 会来调它们。
- `eventData.delta` 是这一帧鼠标移动了多少。除以 `canvas.scaleFactor`，是因为画布可能被缩放，不除的话拖起来会比鼠标更快或更慢。
- 卡片越靠右，越逆时针转一点；越靠左，越顺时针转一点。

### 6. 把脚本挂到卡上

等编译结束，没有红字之后，把 `CardSwipe` 从 Project 拖到 Hierarchy 里的 `Card` 上。也可以点 `Card`，在 Inspector 最下面 Add Component，搜索 `CardSwipe`。

`Card` 上必须已经有 **Image**。没有 Image 的空物体收不到拖动。

## 先懂一个词

**阈值**  
一条看不见的线。拖过这条线才算做出选择。这个 Demo 用 **220** 个界面单位。没过线就当玩家反悔。

**协程 Coroutine**  
`IEnumerator` 加上 `yield return null`，可以让一段移动分很多帧做完。回弹和飞出都用它，这样卡片是滑过去的，不是瞬移。

## 一步步做

### 1. 换成完整的滑动脚本

打开 `CardSwipe.cs`，整份换成下面的代码。

```csharp
using System;
using System.Collections;
using UnityEngine;
using UnityEngine.EventSystems;

public class CardSwipe : MonoBehaviour, IBeginDragHandler, IDragHandler, IEndDragHandler
{
    public float flyThreshold = 220f;
    public float maxRotation = 15f;
    public float returnDuration = 0.18f;
    public float flyDuration = 0.22f;

    public Action<bool> OnSwiped;

    RectTransform rect;
    Canvas canvas;
    Vector2 homePosition;
    bool dragging;
    bool busy;

    void Awake()
    {
        rect = GetComponent<RectTransform>();
        canvas = GetComponentInParent<Canvas>();
        homePosition = rect.anchoredPosition;
    }

    public void OnBeginDrag(PointerEventData eventData)
    {
        if (busy)
        {
            return;
        }

        dragging = true;
    }

    public void OnDrag(PointerEventData eventData)
    {
        if (!dragging || busy)
        {
            return;
        }

        float scale = canvas != null ? canvas.scaleFactor : 1f;
        rect.anchoredPosition += eventData.delta / scale;

        float amount = Mathf.Clamp(rect.anchoredPosition.x / flyThreshold, -1f, 1f);
        rect.localRotation = Quaternion.Euler(0f, 0f, -amount * maxRotation);
    }

    public void OnEndDrag(PointerEventData eventData)
    {
        if (!dragging || busy)
        {
            return;
        }

        dragging = false;

        if (rect.anchoredPosition.x >= flyThreshold)
        {
            StartCoroutine(Fly(true));
        }
        else if (rect.anchoredPosition.x <= -flyThreshold)
        {
            StartCoroutine(Fly(false));
        }
        else
        {
            StartCoroutine(ReturnHome());
        }
    }

    IEnumerator ReturnHome()
    {
        busy = true;
        Vector2 from = rect.anchoredPosition;
        Quaternion fromRotation = rect.localRotation;
        float time = 0f;

        while (time < returnDuration)
        {
            time += Time.deltaTime;
            float t = Mathf.Clamp01(time / returnDuration);
            rect.anchoredPosition = Vector2.Lerp(from, homePosition, t);
            rect.localRotation = Quaternion.Lerp(fromRotation, Quaternion.identity, t);
            yield return null;
        }

        rect.anchoredPosition = homePosition;
        rect.localRotation = Quaternion.identity;
        busy = false;
    }

    IEnumerator Fly(bool toRight)
    {
        busy = true;
        Vector2 from = rect.anchoredPosition;
        float targetX = toRight ? 1800f : -1800f;
        Vector2 to = new Vector2(targetX, from.y + 40f);
        float time = 0f;

        while (time < flyDuration)
        {
            time += Time.deltaTime;
            float t = Mathf.Clamp01(time / flyDuration);
            rect.anchoredPosition = Vector2.Lerp(from, to, t);
            yield return null;
        }

        OnSwiped?.Invoke(toRight);
        busy = false;
    }

    public void ResetToHome()
    {
        StopAllCoroutines();
        dragging = false;
        busy = false;
        rect.anchoredPosition = homePosition;
        rect.localRotation = Quaternion.identity;
    }
}
```

`OnSwiped` 是一张「飞完了」的通知。`true` 表示飞向右边，`false` 表示飞向左边。今天先用一个很短的测试脚本接收它。

### 1. 新建 `MoneyFormat.cs`

```csharp
using System;

public static class MoneyFormat
{
    public static string Dollars(int dollars, bool withSign)
    {
        int abs = Math.Abs(dollars);
        string body;

        if (abs >= 1000000)
        {
            body = "$" + (abs / 1000000f).ToString("0.#") + "M";
        }
        else if (abs >= 1000)
        {
            body = "$" + (abs / 1000f).ToString("0.#") + "K";
        }
        else
        {
            body = "$" + abs;
        }

        if (!withSign)
        {
            return dollars < 0 ? "-" + body : body;
        }

        if (dollars > 0)
        {
            return "+" + body;
        }

        if (dollars < 0)
        {
            return "-" + body;
        }

        return body;
    }
}
```

`withSign` 为 true 时，加钱会带 `+`，用来做「刚刚变化了多少」的提示。财富余额本身用 `withSign: false`。

```csharp
using UnityEngine;
using TMPro;

public class GameController : MonoBehaviour
{
    public CardSwipe card;
    public SeasonDeck deck;

    public TMP_Text questionText;
    public TMP_Text leftText;
    public TMP_Text rightText;
    public TMP_Text resultText;

    public TMP_Text performanceText;
    public TMP_Text moraleText;
    public TMP_Text fansText;
    public TMP_Text wealthText;

    public int performance = 50;
    public int morale = 50;
    public int fans = 50;
    public int wealth = 2000000;

    int index;

    void Start()
    {
        card.OnSwiped += HandleSwiped;
        ShowCard();
        RefreshStats();
    }

    void OnDestroy()
    {
        if (card != null)
        {
            card.OnSwiped -= HandleSwiped;
        }
    }

    void HandleSwiped(bool choseRight)
    {
        CardDefinition data = deck.cards[index];
        StatChange effect = choseRight ? data.rightEffect : data.leftEffect;

        performance += effect.performance;
        morale += effect.morale;
        fans += effect.fans;
        wealth += effect.wealth;

        string result = choseRight ? data.rightResult : data.leftResult;
        resultText.text = result + "\n财富 " + MoneyFormat.Dollars(effect.wealth, true);

        RefreshStats();

        index++;
        if (index >= deck.cards.Length)
        {
            index = 0;
        }

        card.ResetToHome();
        ShowCard();
    }

    void ShowCard()
    {
        CardDefinition data = deck.cards[index];
        questionText.text = data.question;
        leftText.text = data.leftChoice;
        rightText.text = data.rightChoice;
    }

    void RefreshStats()
    {
        performanceText.text = "实力 " + performance;
        moraleText.text = "士气 " + morale;
        fansText.text = "粉丝 " + fans;
        wealthText.text = "财富 " + MoneyFormat.Dollars(wealth, false);
    }
}
```

```csharp
void HandleSwiped(bool choseRight)
{
    if (endPanel.activeSelf)
    {
        return;
    }

    CardDefinition data = deck.cards[index];
    StatChange effect = choseRight ? data.rightEffect : data.leftEffect;
    Apply(effect);

    string result = choseRight ? data.rightResult : data.leftResult;
    resultText.text = result + "\n财富 " + MoneyFormat.Dollars(effect.wealth, true);
    RefreshStats();

    if (IsBankrupt())
    {
        ShowEnd("俱乐部破产");
        return;
    }

    if (IsSeasonFailed())
    {
        ShowEnd("赛季失败");
        return;
    }

    index++;
    roundCount++;
    card.ResetToHome();
    ShowCard();
}

void Apply(StatChange effect)
{
    performance += effect.performance;
    morale += effect.morale;
    fans += effect.fans;
    wealth += effect.wealth;
}

bool IsBankrupt()
{
    return wealth <= 0;
}

bool IsSeasonFailed()
{
    return performance <= 0 || morale <= 0 || fans <= 0;
}

void ShowEnd(string title)
{
    endPanel.SetActive(true);
    endTitle.text = title;
}

public void Restart()
{
    performance = 50;
    morale = 50;
    fans = 50;
    wealth = 2000000;
    index = 0;
    roundCount = 1;
    resultText.text = "";
    endPanel.SetActive(false);
    card.ResetToHome();
    ShowCard();
    RefreshStats();
}
```

# 第 9 个工作日（10 月 7 日）：把手感和数字反馈做出来

## 今天结束时你应该看到

拖动有旋转，没过线会弹回去，过线会飞出。飞出后下一张从稍微缩小、稍微靠下的状态回到正常大小。选择之后，结果区能看见这次财富是 `+$800K` 还是 `-$500K`，四项数字会从旧值变到新值，而不是瞬间跳过去。

不要为了动画去换一整套插件。下面这套用协程就够。如果你已经会用 DOTween，可以用它做同样的移动，规则不要改。

## 一步步做

### 1. 下一张卡的进入

`CardBack` 平时放在主卡后面：锚点位置 Y 为 `-24`，缩放 `0.96`。

主卡飞出并 `ResetToHome` 之后，不要让它突然出现。给 `CardSwipe` 加一个进入动画：

```csharp
public IEnumerator PlayEnter()
{
    busy = true;
    Vector2 from = homePosition + new Vector2(0f, -24f);
    Vector3 fromScale = Vector3.one * 0.96f;
    rect.anchoredPosition = from;
    rect.localScale = fromScale;
    rect.localRotation = Quaternion.identity;

    float duration = 0.2f;
    float time = 0f;
    while (time < duration)
    {
        time += Time.deltaTime;
        float t = Mathf.Clamp01(time / duration);
        rect.anchoredPosition = Vector2.Lerp(from, homePosition, t);
        rect.localScale = Vector3.Lerp(fromScale, Vector3.one, t);
        yield return null;
    }

    rect.anchoredPosition = homePosition;
    rect.localScale = Vector3.one;
    busy = false;
}
```

`GameController` 在显示下一张之前：

```csharp
card.ResetToHome();
ShowCard();
StartCoroutine(card.PlayEnter());
```

`ResetToHome` 会停掉协程，所以要先 Reset，再 `PlayEnter`。不要把这两行顺序倒过来。

### 2. 数字滚动

在 `GameController` 里，改数值之前先把旧的四个数存下来。然后用大约 0.35 秒插值到新的数。

```csharp
System.Collections.IEnumerator AnimateStats(int fromP, int fromM, int fromF, int fromW)
{
    float duration = 0.35f;
    float time = 0f;

    while (time < duration)
    {
        time += Time.deltaTime;
        float t = Mathf.Clamp01(time / duration);
        performanceText.text = "实力 " + Mathf.RoundToInt(Mathf.Lerp(fromP, performance, t));
        moraleText.text = "士气 " + Mathf.RoundToInt(Mathf.Lerp(fromM, morale, t));
        fansText.text = "粉丝 " + Mathf.RoundToInt(Mathf.Lerp(fromF, fans, t));
        int shownWealth = Mathf.RoundToInt(Mathf.Lerp(fromW, wealth, t));
        wealthText.text = "财富 " + MoneyFormat.Dollars(shownWealth, false);
        yield return null;
    }

    RefreshStats();
}
```

`HandleSwiped` 里在 `Apply` 之前记下旧值，`Apply` 之后 `StartCoroutine(AnimateStats(...))`。

财富变化那一行你在第 4 天已经放进 `resultText`。今天只确认它够大、颜色和余额不一样。加钱用一种颜色，减钱用另一种颜色。可以在代码里：

```csharp
resultText.color = effect.wealth >= 0 ? new Color(0.5f, 0.9f, 0.55f) : new Color(0.95f, 0.45f, 0.4f);
```

### 3. 拖动时的左右提示

可选，但很加分：拖向右边时，右边选项文字变亮；拖向左边时，左边变亮；回到中间时两个都恢复。在 `CardSwipe.OnDrag` 里根据 `anchoredPosition.x` 判断即可。这个效果做不完也不要耽误第 10 天打包。

# 第 10 个工作日（10 月 8 日）：打包，放到别人能打开的地方

## 今天结束时你应该看到

- 一个 Windows 压缩包，别人解压后能玩完整的 10 张。
- 一个 WebGL 压缩包，上传到 itch.io 之后，浏览器里能玩。
- 你自己在打包版本里通关一次、失败一次、重新开始一次。

今天不加重玩以外的新功能。发现bug 只修会让人玩不下去的：拖不动、卡死、打完没结算、按钮无效、打包打不开。

## Windows

1. 确认 Build Profiles 里只有 `SampleScene`，并且已勾选。
2. 平台是 Windows。
3. Product Name 改成你要给人看的游戏名。Company Name 填小组或你的名字。
4. Build 到一个空文件夹，例如 `D:\Unity\Builds\BasketballDemo-Windows`。
5. 把整个文件夹压成 zip。不要只发一个 exe。Unity 旁边的 `*_Data` 文件夹和 Unity 播放器文件必须在一起。

在另一台没装这个工程的电脑上打开一次。没有第二台电脑，就退出 Unity 再打开 exe。

## WebGL

第一次切换到 WebGL 会比较久，留出半小时到一小时。

1. Build Profiles 里选 WebGL，点 Switch Platform，等进度条结束。
2. Player Settings 里可以先用默认画质。如果浏览器里非常卡，再把质量调低，不要今天重新做资源。
3. Build 到空文件夹，例如 `D:\Unity\Builds\BasketballDemo-WebGL`。
4. 这个文件夹里要有 `index.html`，以及 `Build` 文件夹。
5. 进入该文件夹，把里面的文件打成 zip。zip 打开后第一层就应该看到 `index.html`，不要多包一层外层文件夹。itch.io 认的是这个结构。

## itch.io

1. 注册并新建一个项目。
2. Kind of project 选 HTML。
3. 上传 WebGL 的 zip。
4. 勾选「这个文件要在浏览器里播放」。
5. 宽高先填 960×600，或者 1280×720。保存后用 itch 给的链接自己点开。
6. 嵌入页面里再拖一次卡。浏览器里的鼠标和 Unity 编辑器里偶尔不一样，以网页上的手感为准。拖动阈值如果在网页里很难触发，把 `flyThreshold` 从 220 改到 160，重新 Build 一次 WebGL。

Windows 的 zip 也可以作为同一个 itch 页面的下载文件，让不想用浏览器的人下载。

- 重新开始能立刻再玩一局。
- Console 里没有你没看过的红色报错。打包前在编辑器里看一次即可。
